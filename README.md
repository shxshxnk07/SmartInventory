# SmartInventory

How to Run the Application
Step 1: Install Requirements
Make sure you have Python installed. Then open your terminal (or command prompt) and run the following commands to install the required packages:

pip install flask
pip install reportlab
Note: datetime is a built-in Python module, so you do not need to install it separately.

Step 2: Run the Application
Navigate to the project directory in your terminal and run:

python app.py
The application should now be running, and you can access it via your browser.
